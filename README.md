# 🏀 Stat Player : Basket
Appli Android de statistiques de match : joueurs, temps de jeu, points, rebonds, contres, fautes, pertes de balle, défenses réussies, passes, lancers francs.
Données 100 % locales (aucune permission Internet), code PIN, export et effacement.

**Version iPhone :** https://vonmi97-spec.github.io/Stat-Player-Basket/ — ouvrir dans Safari, Partager → « Sur l’écran d’accueil ».
L'APK est compilé automatiquement par GitHub Actions (onglet Actions / Releases).
